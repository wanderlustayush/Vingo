# 🍔 Vingo – Food Delivery App (MERN)

A full-stack food delivery web application built using the **MERN stack** with Real-time order tracking, JWT authentication, and role-based dashboards.

---

## 🚀 Tech Stack

Frontend
- React.js
- Context API
- Socket.io client
- Axios

Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Socket.io

Other
- Cookies Auth
- REST APIs
- CORS
- dotenv

---

## ✨ Features

### 👤 User
- Register / Login (JWT cookies)
- Browse food items
- Add to cart
- Place orders
- Real-time order tracking

### 🏪 Shop Owner
- Manage shop
- Add / update items
- Accept orders
- Live order updates

### 🚚 Delivery
- View assigned deliveries
- Update delivery status

### ⚡ System
- Role-based authentication
- Secure cookies auth
- Real-time updates using Socket.io
- Clean MVC architecture
